# 卡诺克阵容手册

独立的 Windows BepInEx 插件，与 BazaarPlusPlus 一起加载。提供卡诺克七条路线的前、中、后期阵容参考，结合实时场上与仓库显示持有情况。路线由人工维护，卡牌身份、说明和美术读取本机游戏数据。

## 界面与操作

七个流派按钮可直接切换路线，三个阶段页签切换前、中、后期。每个阶段按“基础组件 + 可选组件”显示原生卡图，图上方列出本机模板的物品类型标签；基础组件明确标出核心或过渡核心，可选组件显示用途，替换方案标出替换对象。可选牌中的“核心替代”仍是备选方案。术语定义见 [CONTEXT.md](CONTEXT.md)。

每个阶段的“参考站位”按占格比例显示基础组件的左到右顺序、必要隔离位和剩余空间，点击方块查看对应卡牌。它是参考顺序，不映射当前实际槽位，也不会自动移动物品。飞鼠、水囊、帐篷、面具等方向或邻接要求直接标在图下；条件性收益仍需核对暴怒、半血、辉耀等实际状态。

“基础在场”和基础占格只统计基础组件，仓库和可选牌不增加进度。可选组件按短板择取，不能把整个备选列表同时照搬上场。点击卡牌查看完整搭配条件、换入后的站位提示、替换对象、单项组件占格和本机起始品质说明；需要保留隔离位时另显示含间隔的占格。已有卡牌另外显示持有位置及当前品质。相邻、左右和怒火等条件仍需按实际场上摆位核对。

默认跟随当前天数，并按场上辨识牌匹配路线。手动选择流派或阶段后保持浏览位置；“匹配持有”和“跟随天数”分别恢复自动匹配。匹配只说明实际场上的辨识牌，流派列表保持固定顺序。没有辨识核心时保留当前路线并显示“等待核心”，新核心到手后继续自动匹配。阶段思路直接显示，“转型与技能”和攻略来源可展开。标题栏只保留同步状态和必要操作，金币、等级、口号及操作教学不再占用面板。

拖动标题栏移动面板；“收起”缩成显示当前路线和阶段的小条，“展开”恢复。返回按钮或 Esc 退出详情；F9 显示或隐藏，F10 重新同步。

## 资料与实时状态

`strategies.json` 是路线、来源和复核记录的唯一来源。资料综合 Mobalytics 卡诺克专项攻略、Season 18 阵容总结及 Bazaar Builds 历史攻略，再按官方更新和本机模板复核。阶段是规划分段，不是卡牌出现日；历史攻略不代表当前强度排名，更新需人工重新核对。

场上与仓库分别显示，仓库不计为生效联动。只有游戏快照与本地响应匹配且新鲜时才显示实时持有；菜单、回放、其他英雄、未知状态或不可读库存会暂停核对。断联或数据库更新期间仍可浏览最后成功加载的静态资料，持有判断关闭。本机模板未复核、资料不可读或尺寸不可用时暂停站位图。模板变化提示保持可见，卡图缓存随模板版本释放并重新加载。

物品标签取自本机模板的显式类型，使用游戏原生中文翻译；不混入伤害、灼烧等效果关键词。仓库类型继承等战斗内变化仍以当前游戏卡面为准。详情效果来自本机起始品质模板，无法解析的能力和光环数值显示“数值待确认”；附魔与实际数值以游戏中的当前卡面为准。失落之刃需要单主动物品体系，未列作普通生命武器组合的直接替换。

## 本机配置与安装

需要已安装的 The Bazaar、BepInEx、Python 3.10 或更新版本及 .NET SDK 10。Python 只用标准库；游戏程序集和卡图由本机游戏提供，不随源码分发。

本目录的 `settings.example.json` 列出配置项。需要自定义游戏缓存路径时，将它复制为 `settings.json`；留空或无配置文件时使用当前 Windows 用户的游戏缓存。旧版模型配置会被忽略，程序不读取密钥文件，也不发送模型请求。

关闭游戏后构建、检查并安装：

```powershell
.\tools\test.ps1 -PythonExecutable 'D:\miniconda\python.exe'
.\tools\install.ps1 -GameDirectory 'D:\SteamLibrary\steamapps\common\The Bazaar' -PythonExecutable 'D:\miniconda\python.exe'
```

通过 Steam 启动游戏。安装脚本写入独立插件的源码、Python 和运行目录位置；移动源码目录或更换 Python 后需要重新安装。开发新版本时使用独立目录，避免改变已安装 DLL 引用的 Python 源码。`tools/uninstall.ps1` 移除独立插件。

测试覆盖组件与替换约束、基础占格、实时状态失效、文件共享、数据库更新失败，以及实际编译的界面选择状态。原生卡图显示、收起展开、拖动和快捷键需在游戏内另行验证。运行目录只写本地同步文件和诊断日志。
