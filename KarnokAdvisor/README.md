# 卡诺克阵容手册

独立的 Windows BepInEx 插件，与 BazaarPlusPlus 一起加载。提供卡诺克七条路线的前、中、后期阵容参考，结合实时场上与仓库显示组件持有情况。所有资料从本机游戏缓存读取。

## 界面与操作

七个流派按钮可直接选择伙伴暴怒、自减速蚺蛇、弹药装填、减速剧毒、生命武器、极光治疗或灼烧路线。三个阶段页签分别展示对应组合，图卡使用游戏原生美术，标明核心、功能、起始品质、占格及当前持有位置。点击图卡查看本机卡面说明；返回按钮或 Esc 回到组合。

默认跟随当前天数，并按场上辨识核心匹配路线。手动选择流派或阶段后保持你的浏览位置；“匹配持有”和“跟随天数”可分别恢复自动匹配。匹配只说明实际持有组件，流派列表保持固定顺序。

阶段思路放在组合下方，持有与转型、技能与注意条件、资料与版本可分别展开。拖动标题栏移动面板；“收起”缩成小条，“展开”恢复手册。F9 显示或隐藏，F10 重新同步。图卡顺序不代表摆位，相邻与左右要求仍看阶段说明和游戏卡面。

## 资料与实时状态

`strategies.json` 是路线、来源和复核记录的唯一来源。资料综合 Mobalytics 卡诺克专项攻略、Season 18 阵容总结及 Bazaar Builds 历史攻略，并按 19.0 更新和本机卡牌模板复核。旧攻略强度排名未用作推荐；资料更新需人工重新核对。

D1–3、D4–7、D8+ 是规划分段，不是卡牌获取限制。品质表的首个正权重日期也不等于单卡掉率。组合是选牌参考，不能保证十胜；当前格子不足时，先考虑可用组件。

“场上”和“仓库”分别显示，仓库不计为生效联动。只有游戏快照与本地资料响应匹配且新鲜时才显示实时持有；菜单、回放、其他英雄、未知状态或不可读库存会暂停核对。断联及数据库更新期间仍可浏览最后成功加载的静态资料，持有判断关闭。模板变化会提示重新核对卡面。

详情中的效果来自本机起始品质模板，数值占位保留“数值待确认”；若已持有，另外显示当前品质和位置。附魔与实际数值仍以游戏中的当前卡面为准。

## 本机配置与安装

需要已安装的 The Bazaar、BepInEx、Python 3.10 或更新版本及 .NET SDK 10。Python 只用标准库；游戏程序集和卡图由本机游戏提供，不随源码分发。

本目录的 `settings.example.json` 列出配置项。需要自定义游戏缓存路径时，将它复制为 `settings.json`；缓存路径留空或没有配置文件时使用当前 Windows 用户的游戏缓存。旧版模型配置会被忽略，程序不读取密钥文件，也不发送模型请求。

关闭游戏后构建、检查并安装：

```powershell
.\tools\test.ps1 -PythonExecutable 'D:\miniconda\python.exe'
.\tools\install.ps1 -GameDirectory 'D:\SteamLibrary\steamapps\common\The Bazaar' -PythonExecutable 'D:\miniconda\python.exe'
```

通过 Steam 启动游戏。安装脚本为独立插件写入源码、Python 和运行目录的位置；移动目录或更换 Python 后重新安装。`tools/uninstall.ps1` 移除独立插件。

测试覆盖本地资料、实时状态失效、文件共享、数据库更新失败，以及实际编译的界面选择状态。卡图、收起展开、拖动与快捷键还需在游戏内验证。运行目录只写本地同步文件和诊断日志。
