# 阵容手册术语

| 术语 | 含义与边界 |
|---|---|
| 基础组件 | 当前流派、当前阶段的一种参考搭配。基础占格和“基础在场”只统计这一组，不含可选组件。它不是唯一正确阵容。 |
| 参考站位 | 基础组件按 `base_items` 顺序从左到右摆放，`positioning` 拥有隔离位和关键邻接要求。物品占格、隔离位、剩余空位分别绘制；它不对应当前场上实际 socket 编号。 |
| 阶段核心 | 基础组件中承担当前搭配主要机制的牌，由阶段的 `core_items` 明确指定。共享的前期牌标为“过渡核心”。 |
| 可选组件 | 按短板择取的补充或替换方案。每项有简短用途、完整条件和可选的基础替换对象；不要求全部同时上场。 |
| 核心替代 | 替换对象包含阶段核心的可选组件。它仍是可选方案，不计入基础进度。替换后要重新核对触发链。 |
| 流派辨识牌 | 路线的 `anchors`，用于按实际场上组件匹配流派。与阶段核心分开，长矛等共用过渡牌不会因此锁定终局流派。 |
| 持有状态 | 场上与仓库分别观测。仓库不算在场联动；快照失效时持有状态为未核对。 |
| 赛季参考 | 路线的 `seasons` 指定所属参考分组，`season_notes` 说明来源或复核性质。S18 只收录明确的当季体系；界面阶段和组件按本机当前模板适配。S19 包含当前机制参考与实战终盘样例。分组不会把详情卡面回退到历史版本，也不表示作者逐阶段展示了所有组件。 |

`strategies.json` 拥有流派、阶段、组件、条件和来源。`strategy.py` 的 `StrategyBook.stage` 将它们映射到本机唯一卡牌模板，并计算基础占格和单项替换后的占格；站位总占格另外包含保留的隔离位。可选牌只有显式声明 `fills_gap_after` 才能填该隔离位；替换掉隔离位锚点时不再保留其空位。这些计算不代表当前场上一定能直接摆入或所有联动条件已经成立。游戏模板变化时保留静态资料并提示核对卡面。

`StrategyBook.reference` 在每个赛季内计算场上辨识牌与角色覆盖，`matched_route_ids` 列出所有同分最佳路线。`ReferenceViewState` 只在当前赛季可见路线内选择，优先保留当前同分路线；没有辨识核心时保留有效浏览位置。`advisor.DOCUMENT_KIND` 与 `ReferenceViewState.DocumentKind` 定义本地响应协议版本，旧协议不能供应实时持有。
